
# Döviz Kuru Uygulaması

Döviz Kuru Uygulaması, XML verilerini kullanarak anlık döviz kurlarını çekmek ve kullanıcıya sunmak amacıyla geliştirilmiştir. Uygulama, TCMB (Türkiye Cumhuriyet Merkez Bankası) veya benzeri kaynaklardan XML formatında döviz verilerini alarak işlem yapar.

## 📌 Proje Özellikleri

- **Anlık döviz kuru takibi**
- **XML formatında veri çekme ve işleme**
- **Kullanıcı dostu ve basit arayüz-Çok Basit**

## 🚀 Kullanılan Teknolojiler

- **C#**
- **XML Veri İşleme**



## ⚙️ Kurulum

1. **Projeyi klonlayın:**
   ```sh
   git clone https://github.com/bhmberkan/dovizuyg-xml.git
   ```
2. **Bağımlılıkları yükleyin:**
   - Gerekli NuGet paketlerini yükleyin.
3. **Projeyi çalıştırın:**
   - Visual Studio veya uygun bir IDE kullanarak projeyi açın ve çalıştırın.
   - IIS Express veya yerel sunucu kullanarak uygulamayı başlatın.
